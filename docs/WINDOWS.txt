메소 라이브 룰렛 0.0.1 — Windows 11 64비트

1. ZIP을 내려받은 경우 압축을 풀어 주세요.
2. MesoLiveRoulette-0.0.1-win-x64.exe를 더블클릭합니다.
   Node.js, npm, 관리자 권한은 필요하지 않습니다.
3. 브라우저 관리 화면이 자동으로 열립니다.
4. 연결 & OBS에서 방송 URL과 후원 연결을 설정합니다.
   치지직/SOOP: 공개 방송 URL. 투네이션: OBS 알림 위젯 URL.
   YouTube 및 치지직 공식 모드: 개발자 앱 설정 후 계정 연결.
5. 룰렛 조건 금액, 확률, 회전 시간을 저장하고 OBS 주소를 복사합니다.
6. 방송하는 동안 실행 창을 열어 두세요. Ctrl+C 또는 창 닫기로 종료합니다.

설정·메소 잔액·인증 정보는 %LOCALAPPDATA%\MesoLiveRoulette\data 에 저장됩니다.
EXE를 교체해도 보존됩니다. 이 폴더에는 비밀 키가 있으므로 공유하지 마세요.
브라우저가 안 열리면 http://127.0.0.1:3000 에 접속합니다.
관리자 키는 저장 폴더의 keys.json 파일에서 admin 항목을 확인합니다.
관리 화면을 새로 열거나 다른 브라우저를 사용할 때는 키 입력이 필요할 수 있습니다.
이미 실행 중이면 이전 창을 사용하거나 닫은 뒤 다시 실행하세요.

인터넷 연결이 필요합니다. 테스트 후원은 실제 잔액에 반영됩니다.
비공식 플랫폼 연결은 서비스 변경에 영향을 받을 수 있으며 제한 방송은 지원하지 않습니다.
실제 유료 후원 수신은 아직 검증하지 않았습니다. 지원 범위는 GitHub README를 확인하세요.
https://github.com/yukwanwoo/apiSetting

이 초기 배포본은 코드 서명되지 않았으므로 Windows SmartScreen 경고가 나올 수 있습니다.
GitHub 공식 릴리스에서 받은 파일인지 확인하고, SHA256SUMS.txt로 무결성을 확인하세요.
