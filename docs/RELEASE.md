Windows 11 64비트용 0.0.2 배포입니다. **다운로드는 ZIP 하나만 제공**합니다.

- ZIP을 풀면 EXE, `data/`, 사용 설명서, 라이선스, EXE 체크섬을 포함한 하나의 폴더가 나옵니다. EXE를 더블클릭하세요. Node.js나 관리자 권한은 필요하지 않습니다.
- 설정·잔액·키는 **EXE 옆 `data/`**에 저장합니다. 폴더 전체를 옮겨도 유지됩니다. 업데이트 시 기존 `data/`를 새 EXE 옆에 보관하세요.
- 처음 실행할 때 새 `data/`에 실제 데이터가 없으면 기존 0.0.1의 AppData 데이터를 한 번 복사합니다. 원본은 보존합니다.
- 기본 알림음을 추가했습니다. 룰렛 설정에서 0~100% 음량을 조절하고 저장하세요. 0%는 음소거입니다. OBS 룰렛 회전 시작 시 한 번 울리며 미리보기·메소 화면은 무음입니다.
- OBS 룰렛은 회전과 결과 표시 시간이 끝나면 숨겨집니다. 메소 잔액 화면은 계속 표시됩니다.
- 기본 공격 가격은 **1,000원**, 방어는 **1,100원**입니다. 0부터 1천만까지 100만 단위로 추첨하며, 0메소 9.0%·나머지 각 9.1%로 합계 100%입니다.
- 기존에 편집한 규칙은 보존하고, 이전 기본 항목·가격을 그대로 쓰던 룰렛만 새 기본값으로 갱신합니다.

Windows CI에서 EXE 실행, 내장 화면·알림음 파일, 인증, 룰렛 정산, 폴더 이동 후 잔액·키·음량 유지를 검증합니다. 브라우저 테스트에서 룰렛 표시·숨김, 알림음 재생 요청·음량·음소거와 미리보기 중복 재생 방지를 확인합니다. 실제 OBS에서의 소리 출력과 실제 유료 후원은 아직 검증하지 않았습니다.
