**0.0.4 — 룰렛 표시·알림음 설정과 스튜디오 제어 기능**입니다. Windows 11 64비트용 폴더형 ZIP 하나만 제공합니다.

- 룰렛 전체 크기를 25~150%로 조절하며 저장하면 OBS에 즉시 적용합니다. 100%는 기존 크기입니다.
- 룰렛별 상단 제목·후원자 문구·후원 정보 코멘트를 템플릿으로 편집합니다. 기본 문구는 유지하며 후원자·룰렛·플랫폼·금액 변수를 사용할 수 있습니다.
- 기본 알림음, 자체 제작 짤랑 효과음, 맑은 벨 중 선택하거나 음성 파일을 업로드합니다. 짤랑은 투네이션 원본이 아닌 직접 제작한 소리입니다. 전체 음량 조절을 유지합니다.
- 업로드 파일은 최대 20MB·3분, 브라우저에서 재생 가능한 WAV·MP3·OGG·M4A 등을 지원합니다. EXE 옆 `data/sounds/`에 WAV로 저장하며 최대 30개까지 보관·삭제할 수 있습니다.
- 새 소리 선택 시 시작 0초, 종료는 회전 + 결과 표시 시간으로 자동 설정합니다. 1초 회전 + 1.5초 결과이면 5초 음성도 앞 2.5초가 기본값입니다. 시작·종료 지점을 직접 편집하고 선택 구간을 미리 들을 수 있습니다. 룰렛 표시 종료 시 소리도 멈춥니다.
- 저장하고 종료 버튼은 확인 후 편집 중인 룰렛 설정·방송 URL, 잔액·기록을 저장하고 프로그램 전체를 종료합니다. 취소 또는 저장 실패 시 계속 실행합니다. 앱 인증 정보는 해당 저장 버튼으로 먼저 저장하세요. 진행·대기 중인 룰렛은 다음 실행에서 재개합니다.
- 라이브 스튜디오에서 메소를 수동 추가·감소할 수 있습니다. 룰렛 진행 중에도 현재 잔액에 반영하고 OBS 및 변동 내역을 갱신합니다.
- EXE 옆 `data/`만 사용하는 방식과 SOOP 입장 티켓·진단 기능을 유지합니다. AppData는 읽거나 복사하지 않습니다.

업데이트: 기존 프로그램을 종료하고 ZIP을 푼 뒤 기존 EXE 옆 **data 전체**를 새 EXE 옆으로 옮기세요. 설정·잔액·키·업로드 음성이 유지됩니다. 기존 설정의 크기·코멘트·알림음은 현재 기본값으로 유지합니다.

검증: 서버·프로토콜 테스트, 실제 브라우저의 음성 업로드·자동/사용자 지정 구간 재생·OBS 표시·수동 증감·종료 취소/확인, Windows EXE의 폴더 이동·파일 유지·저장 후 종료를 확인합니다. 사용자 진단에서 치지직 및 SOOP 후원 수신이 확인됐으며 YouTube·투네이션의 실제 유료 후원 수신은 아직 확인되지 않았습니다.

ZIP에는 EXE, data 안내, 설명서, 라이선스와 EXE 체크섬이 들어 있습니다. Node.js 설치는 필요하지 않습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
