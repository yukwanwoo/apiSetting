**0.0.5 — 라이브 스튜디오에서 즉시 미리보기와 잔액 관리**입니다. Windows 11 64비트용 폴더형 ZIP 하나만 제공합니다.

- 후원 코멘트 편집을 라이브 스튜디오의 룰렛 미리보기 아래로 옮겼습니다. 룰렛을 선택해 문구를 편집하면 저장 전에도 미리보기에 바로 반영됩니다. 기본 문구와 템플릿 변수를 유지합니다.
- 크기 조절 대상을 **회전하는 룰렛 애니메이션만**으로 바로잡았습니다. 코멘트와 결과 크기는 유지합니다. 미리보기 아래에서 25~150%로 편집하고 바로 확인할 수 있습니다.
- 미리보기 편집값은 저장해야 OBS에 적용됩니다. 미리보기를 새로 불러와도 현재 편집값을 다시 반영합니다. 설정 저장 버튼을 미리보기 근처에 추가했습니다.
- 메소 잔액 관리를 라이브 스튜디오의 수동 증감 옆으로 옮겼습니다. 음수 허용·시작 메소 설정 저장, 잔액 직접 설정과 초기화를 해당 화면에서 사용할 수 있습니다. 시작 메소 저장만으로 현재 잔액이 바뀌지는 않습니다.
- 기존 알림음 선택·업로드·재생 구간, 수동 메소 증감, 저장 후 종료, SOOP 연결·진단, EXE 옆 data 저장 기능을 유지합니다.

업데이트: 프로그램을 종료하고 ZIP을 푼 뒤 기존 EXE 옆 **data 폴더 전체**를 새 EXE 옆으로 옮기세요. 설정·잔액·키·업로드 음성이 유지됩니다. 0.0.4의 크기 설정 백분율은 그대로 유지하되 회전판에만 적용합니다.

검증: 서버·프로토콜 테스트, 실제 브라우저에서 저장 전 코멘트·회전판 크기 즉시 미리보기, 룰렛 선택과 미리보기 재로딩, 코멘트·결과 글자 크기 유지, OBS 저장값 적용, 스튜디오 잔액 설정·수동 증감, 음성 재생·저장 후 종료를 확인합니다. Windows EXE에서 파일·설정 유지와 종료를 검증합니다.

ZIP에는 EXE, data 안내, 설명서, 라이선스와 EXE 체크섬이 들어 있습니다. Node.js 설치는 필요하지 않습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
