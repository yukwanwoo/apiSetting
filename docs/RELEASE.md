**0.7.0 — 라이브 스튜디오 정리 및 오버레이 설정 분리**입니다. Windows 11 64비트용 폴더형 ZIP 하나만 제공합니다.

- 라이브 스튜디오는 기존 상태 카드 → 후원 수신 내역·메소 변동 내역 → 메소 수동 증감·잔액 관리 순서로 배치했습니다.
- 라이브 스튜디오 바로 아래 **오버레이 설정** 탭을 추가했습니다. OBS 브라우저 소스 주소, 룰렛 미리보기·크기·후원 코멘트, 테스트 후원과 OBS 추가 안내를 모았습니다.
- 코멘트·회전판 크기는 입력 즉시 미리보기에 반영되고 저장하면 OBS에 적용됩니다. 코멘트·결과 글자 크기는 유지합니다.
- **연결 & OBS**는 **방송연결**로 변경했습니다. 기존 플랫폼 연결, 설정, 잔액 및 후원 처리 방식은 유지합니다.
- 작은 화면에서도 네 개의 메뉴를 사용할 수 있도록 배치했습니다.

기존 YouTube 공개 팝업 채팅 연결은 비공식 베타 기능으로 유지합니다. 실제 YouTube 방송 접속·유료 후원 수신은 아직 검증하지 못했습니다. 치지직·SOOP 사용자 수신 확인과 기존 알림음·업로드·구간 설정·저장 후 종료 기능을 유지합니다.

업데이트: 프로그램을 종료하고 ZIP을 푼 뒤 기존 EXE 옆 **data 폴더 전체**를 새 EXE 옆으로 옮기세요. 설정·잔액·키·업로드 음성이 유지됩니다. AppData는 읽거나 자동 복사하지 않습니다. Node.js 설치는 필요하지 않습니다. ZIP에는 EXE, data 안내, 설명서, 라이선스와 EXE 체크섬이 들어 있습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
