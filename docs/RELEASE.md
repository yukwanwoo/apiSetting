EXE 옆 데이터 폴더만 사용하는 **0.0.3-beta.3**입니다. Windows 11 64비트용 ZIP 하나만 제공합니다.

- Windows EXE는 AppData를 읽거나 자동 복사하지 않습니다. DATA_DIR 환경 변수도 무시하고 EXE 옆 `data/`만 사용합니다.
- AppData 원본은 수정하거나 삭제하지 않습니다. 기존 EXE 옆 설정·메소 잔액·키는 유지합니다.
- beta.2의 SOOP 입장 티켓 전달, 재연결 및 진단 기능을 유지합니다. 사용자 진단에서 별풍선 후원 3건 수신과 해석 오류 0건이 확인됐습니다. AppData 초기화가 정상화 원인인지는 확정하지 않았습니다.
- Windows 사용 안내의 로컬 접속 주소를 `http://127.0.0.1:3000`으로 바로잡았습니다.

업데이트: 기존 프로그램을 종료하고 ZIP을 푼 다음 기존 EXE 옆 `data/`를 새 EXE 옆에 옮기세요. 설정·메소·키가 유지됩니다. 완전히 새 설정으로 시작하려면 기존 portable `data/`를 백업해 다른 이름으로 옮겨 두세요. AppData는 더 이상 자동 이전되지 않습니다.

검증: 기존 AppData에 잘못된 JSON을 넣고 DATA_DIR도 해당 폴더로 지정한 상태에서 Windows EXE가 새 portable 설정으로 시작하는지 확인합니다. 폴더 이동 후 메소 잔액·키·음량 유지 및 기존 AppData 원본 보존도 검증합니다.

ZIP에는 EXE, data 안내, 설명서, 라이선스와 EXE 체크섬이 들어 있습니다. Node.js 설치는 필요하지 않습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
