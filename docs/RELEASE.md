SOOP 공개 채팅 입장 방식을 보완한 **0.0.3-beta.2**입니다. Windows 11 64비트용 ZIP 하나만 제공합니다.

- 현재 방송 정보(type=live)를 조회한 뒤 해당 방송의 채팅 접속 정보(type=ch)를 조회합니다. 방송 번호와 방송인 ID가 일치하는지 검사합니다.
- 공개 API가 반환한 채팅 입장 티켓(FTK)을 입장 패킷에 전달합니다. 계정 로그인이나 성인·비밀번호·구독 제한 우회는 하지 않습니다. 서버가 로그인 티켓을 반환한 경우에만 해당 값을 전달합니다.
- 익명 응답은 로그인 티켓(TK) 없이 입장 티켓만 포함할 수 있습니다. 로그인 토큰을 임의로 만들어 채우지 않습니다.
- 재연결마다 접속 정보와 입장 티켓을 새로 조회합니다.
- SOOP 진단에 실제 방송 번호, 채팅방 번호, 서버, 티켓 존재·전달 여부, 연결·재연결 횟수, 접속 및 최근 수신 시각을 추가했습니다. 티켓 값은 화면·진단에 노출하거나 파일에 저장하지 않습니다.
- **SOOP 진단 복사**는 클릭 시 최신 집계를 가져옵니다. 일반 화면은 최대 15초 갱신 지연이 있을 수 있습니다.
- beta.1의 필수 후원 필드 호환 처리, 폴더형 저장, 알림음, 룰렛 자동 숨김을 유지합니다.

업데이트: 기존 프로그램을 종료하고 ZIP을 푼 다음 기존 `data/`를 새 EXE 옆에 옮기세요. 설정·메소·키가 유지됩니다.

로컬 WebSocket으로 입장 티켓이 실제 패킷에 전달되는지, 재연결 후 새 티켓이 사용되는지, 티켓 없는 익명 로그인과 별풍선 파싱 및 민감 정보 비노출을 검증합니다. 실제 SOOP 방송에서 이번 누락이 해결됐는지는 아직 확인되지 않았습니다. 문제가 계속되면 추가 유료 후원 없이 SOOP 진단 복사 결과를 알려주세요.

ZIP에는 EXE, data 안내, 설명서, 라이선스와 EXE 체크섬이 들어 있습니다. Node.js 설치는 필요하지 않습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
