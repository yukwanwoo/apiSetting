내 방송 연결

치지직·SOOP는 공개 방송 URL, 투네이션은 알림 위젯 URL로 연결합니다. YouTube와 치지직 공식 연결은 계정 동의 방식도 지원합니다. 수신 대기와 실제 후원 수신 상태를 구분합니다.

치지직·SOOP는 URL 저장 후 아래 연결 버튼을 누르세요. 치지직 공식 계정 모드는 인증 계정의 후원을 받습니다. 투네이션은 아래의 알림 위젯 URL을 입력해야 후원을 수신합니다.

치지직

개발자 키 없이 공개 방송 URL로 연결합니다. 공식 계정 연결은 운영자 앱 설정 후 선택할 수 있습니다.

URL 연결은 비공식 공개 채팅 방식입니다. 제한 방송은 지원하지 않습니다.

SOOP

공개 방송 URL로 별풍선·영상 별풍선 이벤트를 읽습니다. 계정 비밀번호를 요구하지 않습니다.

공개 채팅 기반 비공식 연동입니다. 성인·구독·비밀번호 제한 방송은 현재 지원하지 않습니다.

투네이션

투네이션 스트리머 설정 → 알림 위젯에서 OBS용 알림창 URL을 복사해 붙여 넣으세요.

알림 위젯 기반 비공식 연동입니다. URL은 연결 권한을 포함하므로 다른 사람에게 공유하지 마세요. 투네이션 자체 테스트 알림은 잔액에 반영하지 않습니다.

YouTube

방송 URL 저장 후 Google 계정을 연결하세요. KRW Super Chat·Super Sticker를 수신합니다.

채널별 과거 후원을 모두 가져오는 기능이 아닙니다. 연결된 동안 전달되는 이벤트를 처리합니다. 이벤트에 거래 ID가 없는 플랫폼은 연결이 끊긴 구간의 누락·재전송을 완전히 판별할 수 없습니다.

서비스 운영자 설정 · 개발자 앱 등록

배포 운영자가 개발자 앱을 한 번 등록하면 방송자는 위 계정 연결 버튼을 사용합니다. 개인 PC에 설치한 경우에는 설치자가 운영자입니다. 현재 앱은 설치별로 한 방송자의 설정을 보관합니다.

치지직 개발자 앱

앱의 ‘유저 정보 조회’와 ‘후원 조회’ 권한을 활성화하고 리디렉션 URI를 정확히 등록하세요.

Google OAuth 앱

YouTube Data API v3 활성화, OAuth 동의 화면, 테스트 사용자 등록이 필요합니다. 자격 증명은 서버 환경 변수 또는 로컬 보호 파일에 보관하며 브라우저에 다시 표시하지 않습니다.

OBS에 추가하기

  1. OBS의 소스 목록에서 + → 브라우저를 선택합니다.
  2. 위 주소를 URL에 붙여 넣고 권장 너비·높이를 입력합니다.
  3. ‘소스가 보이지 않을 때 종료’를 끄면 장면 전환 중에도 애니메이션을 유지할 수 있습니다.
  4. 테스트 후원을 보내 두 오버레이가 함께 반응하는지 확인합니다.

OBS가 다른 컴퓨터에 있으면 localhost 대신 서버의 접근 가능한 주소가 필요합니다. 외부 공개 시 HTTPS와 접근 제어를 설정하세요. 오버레이 URL에는 읽기 전용 키가 포함되므로 공개하지 마세요.
