메소 라이브 룰렛 0.7.0 — Windows 11 64비트

1. ZIP을 바탕화면 등 쓰기 가능한 폴더에 풀어 주세요. 하나의 폴더에 EXE와 data 폴더가 있습니다.
2. MesoLiveRoulette-0.7.0-win-x64.exe를 더블클릭합니다.
   Node.js, npm, 관리자 권한은 필요하지 않습니다.
3. 브라우저 관리 화면이 자동으로 열립니다.
4. 방송연결에서 방송 URL과 후원 연결을 설정합니다.
   치지직/SOOP: 공개 방송 URL. 투네이션: OBS 알림 위젯 URL.
   YouTube 공개 채팅 베타: 팝업 채팅 URL 또는 방송 URL 저장 후 저장한 YouTube 채팅 연결. API 키·계정 연결 불필요.
   YouTube 및 치지직 공식 모드: 선택적으로 개발자 앱 설정 후 계정 연결.
5. 룰렛 설정에서 조건 금액, 확률, 회전 시간을 저장합니다.
   오버레이 설정에서 OBS 주소를 복사하고 미리보기·크기·코멘트 편집 및 테스트 후원을 사용합니다.
   라이브 스튜디오는 상태 카드 → 후원·메소 내역 → 수동 증감·잔액 관리 순서입니다.
6. 방송하는 동안 실행 창을 열어 두세요. 관리 화면의 저장하고 종료 버튼을 누르면 확인 후 현재 설정과 방송 URL을 저장하고 프로그램을 종료합니다.
   취소하면 계속 실행합니다. 앱 인증 정보는 각 저장 버튼으로 먼저 저장하세요. 종료 시 후원 수신과 OBS 실시간 갱신도 멈춥니다.
   진행 중인 룰렛과 대기열은 다음 실행에서 재개합니다. Ctrl+C 또는 창 닫기도 가능합니다.

설정·메소 잔액·인증 정보는 EXE 옆 data 폴더에 저장됩니다.
업데이트 전에 이전 실행 창을 종료하고 기존 data 폴더를 새 EXE 옆에 두세요. EXE와 data를 함께 옮기면 그대로 사용합니다.
AppData를 읽거나 자동 복사하지 않습니다. DATA_DIR 환경 변수도 무시하고 EXE 옆 data만 사용합니다.
이미 EXE 옆 data에 있는 설정은 유지하며 AppData 원본은 수정하거나 삭제하지 않습니다.
이 폴더에는 비밀 키가 있으므로 공유하지 마세요.
브라우저가 안 열리면 http://127.0.0.1:3000 에 접속합니다.
관리자 키는 저장 폴더의 keys.json 파일에서 admin 항목을 확인합니다.
관리 화면을 새로 열거나 다른 브라우저를 사용할 때는 키 입력이 필요할 수 있습니다.
이미 실행 중이면 이전 창을 사용하거나 닫은 뒤 다시 실행하세요.

룰렛 크기: 오버레이 설정 → 미리보기 아래의 룰렛 애니메이션 크기에서 25~150%를 입력합니다.
회전판만 조절하며 코멘트와 결과 크기는 유지합니다. 저장 전에도 미리보기에 바로 반영되고 저장하면 OBS에 적용합니다.
100%는 기존 회전판 크기입니다. 기존 백분율 설정은 회전판에만 적용됩니다.
코멘트: 오버레이 설정 → 미리보기 아래에서 룰렛을 선택해 제목·후원자·후원 정보 문구를 편집합니다.
입력 즉시 미리보기에 반영됩니다. 설정 저장으로 적용하며 빈 문구는 숨깁니다.
변수: {nickname} 후원자, {roulette} 룰렛, {platform} 플랫폼, {amount} 원화 금액, {kind} ATTACK/DEFENSE, {stars} 별풍선 안내, {test} 테스트 안내.
알림음: 룰렛별 기본·자체 제작 짤랑·맑은 벨·업로드 파일 중 선택합니다. 짤랑은 투네이션 원본이 아닌 직접 제작한 효과음입니다.
전체 음량을 조절하고 설정 저장을 누르세요. 0%는 무음입니다.
음성 업로드: WAV·MP3·OGG·M4A 등 브라우저가 재생할 수 있는 파일, 20MB·3분 이하, 최대 30개.
업로드 파일은 data/sounds에 저장되므로 업데이트 시 data 전체를 함께 옮기세요.
새 소리를 선택하면 시작은 0초, 종료는 회전 + 결과 표시 시간으로 자동 설정합니다.
예: 회전 1초 + 결과 1.5초이면 5초 음성도 앞 2.5초가 기본값입니다. 짧은 파일은 끝까지 재생합니다.
자동 종료를 끄면 시작·종료 지점을 직접 설정할 수 있고 선택 구간 듣기로 확인합니다. 룰렛 표시 종료 시 소리도 멈춥니다.
라이브 스튜디오의 메소 수동 증감에서 추가/감소, 금액과 선택 메모를 입력해 잔액 및 OBS에 바로 반영합니다.
수동 증감 옆 메소 잔액 관리에서 음수 허용·시작 메소 설정을 저장하고 잔액 직접 설정·초기화도 사용할 수 있습니다.
시작 메소 설정을 저장하는 것만으로 현재 잔액이 바뀌지 않습니다.
수동 증감은 룰렛 진행 중에도 사용할 수 있습니다. 잔액 직접 설정·초기화는 룰렛 종료 후 가능합니다.
OBS 브라우저 소스의 OBS를 통해 오디오 제어 옵션과 오디오 믹서 설정을 확인하세요.
룰렛은 회전과 결과 표시 후 숨겨집니다. 메소 잔액 화면은 계속 표시됩니다.
기본 공격: 1,000원 / 기본 방어: 1,100원. 0~1천만을 100만 단위로 추첨합니다.
확률: 0메소 9.0%, 나머지 각 9.1%. 직접 편집한 기존 규칙은 보존합니다.

인터넷 연결이 필요합니다. 테스트 후원은 실제 잔액에 반영됩니다.
비공식 플랫폼 연결은 서비스 변경에 영향을 받을 수 있으며 제한 방송은 지원하지 않습니다.
사용자 진단에서 치지직 및 SOOP 후원 수신이 확인됐습니다. 지원 범위는 GitHub README를 확인하세요.
https://github.com/yukwanwoo/apiSetting

이 초기 배포본은 코드 서명되지 않았으므로 Windows SmartScreen 경고가 나올 수 있습니다.
GitHub 공식 릴리스에서 받은 파일인지 확인하고, SHA256SUMS.txt로 무결성을 확인하세요.
SHA256 확인 예: PowerShell에서 Get-FileHash .\MesoLiveRoulette-0.7.0-win-x64.exe -Algorithm SHA256

SOOP 진단: 방송연결의 SOOP 카드에서 패킷·채팅·별풍선 패킷·해석 오류를 확인하세요.
문제가 계속되면 SOOP 진단 복사 버튼의 결과를 전달해 주세요. 키와 채팅 내용은 포함하지 않습니다.
별풍선 5개(500원)도 후원 내역에는 기록되지만 기본 룰렛 금액 조건과 달라 회전하지 않습니다.
beta.2 사용자 진단에서 SOOP 별풍선 후원 3건 수신 및 해석 오류 0건이 확인됐습니다.

입장 티켓 전달됨, 방송 번호, 채팅방 번호, 최근 수신 시각과 재연결 횟수를 확인할 수 있습니다.
진단 복사는 클릭 시 최신 집계를 가져옵니다. 화면의 집계는 최대 15초 지연될 수 있습니다.

YouTube 공개 채팅 베타: 라이브 채팅 메뉴 → 팝업 창의 URL을 복사합니다.
형식: https://www.youtube.com/live_chat?is_popout=1&v=동영상ID
방송연결에서 해당 URL을 저장한 뒤 저장한 YouTube 채팅 연결을 누르세요.
공개 채팅의 원화 Super Chat·Super Sticker만 처리하며 과거 후원·티커 중복·다시보기·외화·멤버십은 제외합니다.
접속 성공은 수신 대기, 실제 후원 처리 후 후원 수신 확인으로 표시됩니다. 문제가 있으면 YouTube 진단 복사를 이용하세요.
접속 토큰·방문자 값은 메모리에서만 사용하고 진단이나 설정 파일에 저장하지 않습니다.
이 클라우드 환경의 YouTube 네트워크 차단으로 실제 방송 접속·유료 후원 수신은 아직 확인하지 못했습니다.
공개 채팅 접근 제한이나 YouTube 변경으로 수신이 끊길 수 있는 비공식 베타 기능입니다.
