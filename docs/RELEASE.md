**0.0.6-beta.1 — YouTube 팝업 채팅 URL 연결**입니다. Windows 11 64비트용 폴더형 ZIP 하나만 제공합니다.

- `https://www.youtube.com/live_chat?is_popout=1&v=동영상ID`를 입력하는 비공식 공개 채팅 모드를 추가했습니다. 일반 watch·live·youtu.be 방송 URL도 지원합니다.
- **연결 & OBS → YouTube 팝업 채팅 / 방송 URL → 방송 URL 저장 → 저장한 YouTube 채팅 연결** 순서로 사용합니다. API 키나 Google 계정 연결이 필요하지 않습니다.
- 공개 채팅의 원화 Super Chat·Super Sticker 후원자·금액을 처리합니다. 처음 표시된 후원과 연결 시작 이전 후원, 티커 중복·다시보기·일반 채팅·멤버십·외화는 제외합니다. 재시작 후 중복 방지를 유지합니다.
- 수신 대기와 후원 수신 확인을 구분하고 YouTube 진단 복사를 추가했습니다. 접속 토큰·공개 페이지 API 키·방문자 값은 메모리에서만 사용하며 진단·설정 파일에 저장하지 않습니다.
- Google 계정 연결 방식은 선택적 공식 모드로 유지합니다. 기존 인증 설치는 공식 모드를 유지하며 URL 연결 버튼으로 공개 모드로 전환할 수 있습니다.
- 0.0.5의 스튜디오 즉시 미리보기, 회전판 크기·코멘트, 잔액 관리, 알림음 업로드·구간 설정, 저장 후 종료, EXE 옆 data 저장을 유지합니다.

**실제 YouTube 방송 접속·유료 후원 수신은 아직 검증하지 못했습니다.** 이 클라우드의 YouTube 접속이 차단돼 응답 형식 기반 모의 테스트로 채팅 접속·폴링·후원 정산·과거 제외·중복 방지·제한/오류 상태를 검증했습니다. 로그인·지역·성인·회원 제한 방송, 요청 차단, 채팅 비활성 또는 YouTube 내부 변경으로 연결이 실패할 수 있습니다. 문제가 있으면 추가 유료 후원 없이 YouTube 진단 복사 결과를 확인하세요.

업데이트: 프로그램을 종료하고 ZIP을 푼 뒤 기존 EXE 옆 **data 폴더 전체**를 새 EXE 옆으로 옮기세요. 설정·잔액·키·업로드 음성이 유지됩니다. Node.js 설치는 필요하지 않습니다. ZIP에는 EXE, data 안내, 설명서, 라이선스와 EXE 체크섬이 들어 있습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
