**0.0.9 — 메소 아이콘 및 알림음 표시 이름 변경**입니다. Windows 11 64비트용 폴더형 ZIP 하나만 제공합니다.

- 메소 주머니 이미지를 로그인·메소 라이브 로고, 브라우저 탭 아이콘, 메소 잔액 오버레이 및 Windows EXE 아이콘에 적용합니다.

- 이전 버전의 기본 브라우저 실행 수정과 라이브 스튜디오·오버레이 설정·방송연결 기능을 유지합니다.
