SOOP 후원 수신 호환성과 진단을 위한 **0.0.3-beta.1**입니다. Windows 11 64비트용 ZIP 하나만 제공합니다.

- SOOP 라이브러리가 부가 필드 해석에 실패한 별풍선 메시지를 버리는 경우, 수신 방송인·후원자·별풍선 개수를 검증해 필수 정보로 처리하는 호환 경로를 추가했습니다. 일반·서브 채널·영상 별풍선의 기존 필드 위치만 지원하며 다른 방송인이나 잘못된 개수는 거부합니다.
- 정상 메시지는 기존 경로에서 한 번만 처리합니다. 별풍선 5개도 500원으로 후원 목록에 기록하며, 정확한 금액 조건과 일치할 때만 룰렛이 돌아갑니다.
- 연결 & OBS의 SOOP 카드에 패킷·채팅·별풍선 패킷·해석 오류·호환 처리 수와 최근 오류 코드/필드 수를 표시합니다.
- **SOOP 진단 복사**는 집계 정보만 복사합니다. 비밀 키, 채팅 내용, 후원자 닉네임, 원본 메시지는 포함하지 않습니다. 진단은 실행 중 메모리에만 보관합니다.
- 기존 실행 창을 종료한 뒤 ZIP을 풀고 기존 `data/`를 새 EXE 옆에 옮기세요. 설정·메소 잔액·키는 유지됩니다. 폴더형 저장, 알림음 음량, 룰렛 자동 숨김도 유지합니다.

실제 SOOP 메시지를 확보하지 못했으므로 이번 누락의 원인이 확정된 상태는 아닙니다. 이 베타의 실제 유료 후원 수신은 아직 검증되지 않았습니다. 로컬 실제 바이너리 프레임으로 5개 기록, 10개·11개 룰렛 정산, 부가 필드 호환, 중복 처리 방지 및 잘못된 방송인 거부를 검증합니다. 문제가 계속되면 추가 유료 후원 없이 SOOP 진단 복사 결과를 알려주세요.

ZIP에는 EXE, data 안내, 사용 설명서, 라이선스, EXE 체크섬이 하나의 폴더에 들어 있습니다. Node.js 설치는 필요하지 않습니다. 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
